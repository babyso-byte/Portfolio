# Портфолио Сони Граниной

Статический сайт: обычные HTML-страницы, без сборки.

- `index.html`, `design.html`, `pr.html`, `ai.html`, `pricing.html`, `brief.html`, `about.html`, `contacts.html`, `privacy.html` — страницы
- `assets/style.css` — общие стили, `assets/main.js` — анимации, меню, калькулятор, бриф, отправка форм
- `assets/config.js` — почта и адрес обработчика форм (меняются здесь)
- `assets/img/` — все картинки
- `works/` — клиентские сайты из портфолио
